# ✦ ANTARIKSH

Repository for **Antariksh**, the astronomy club of Vishwakarma Institute of Technology (VIT), Pune. 

## 🛠️ Tech Stack

*   **Frontend Framework**: React.js (Vite)
*   **Routing**: React Router v6

## ⚙️ Local Setup

### Prerequisites
Make sure you have Node.js installed on your local machine.

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/Antariksh-Club/Antariksh.git
cd Antariksh
```

2. **Install dependencies:**
```bash
npm install
```

3. **Start the local development server:**
```bash
npm run dev
```

4. **Launch:** Open your browser and navigate to `http://localhost:5173/`

# ✦ Antariksh Astronomy Club

Welcome to the official web repository of the **Antariksh Astronomy Club**, Vishwakarma Institute of Technology (VIT), Pune. 

Built under the same sky, this platform serves as the central hub for our cosmic voyages, technical dossiers, crew records, and mission logs.

## 🚀 Tech Stack

- **Framework**: React 18
- **Routing**: React Router DOM (v6)
- **Styling**: Custom CSS (Space-tech & Glassmorphic aesthetics) + Bootstrap 5
- **Build Tool**: Vite

## 🌌 Quick Start

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### 2. Installation
Clone the repository and install the required dependencies:

\\\ash
npm install
\\\

### 3. Local Development
Initiate the ignition sequence and start the development server:

\\\ash
npm run dev
\\\

The site will go live at http://localhost:5173.

### 4. Build for Production
To bundle the project for deployment:

\\\ash
npm run build
\\\

To preview the built project locally:

\\\ash
npm run preview
\\\

## 🛰️ Project Structure

- src/pages/ - Contains the primary routing pages (e.g., Home, Projects, Dossier).
- src/components/ - Reusable UI components (Navbar, Footer, etc.).
- src/css/ - Component-specific stylesheets and global theme files.
- public/static/assets/ - Static assets like logos, videos, and images.
