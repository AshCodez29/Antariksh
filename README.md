## 🧭 Overview

Repository for the official website of the Antariksh Astronomy Club, designed to bring the club's activities, people, projects, and visual archive together.

* 📅 **Events** — Upcoming and past events
* 📸 **Media** — Chronological photo archive
* 📰 **Reports** — Event reports and articles
* 🛰️ **Projects** — Club projects and contributions
* 👥 **Team** — Year-wise member profiles
